# Koin

## 导入账单

打开“数据”，选择整理好的 Koin JSON。导入前可查看月份范围及新增、重复、无效记录数量；确认后，已有记录的本机修改会保留。

## 查看与整理

“概览”按月查看消费、退款和分类趋势；“明细”按日期连续浏览，支持指定一天、起止日期范围和日期跳转，滚动时显示当前位置。搜索输入后按回车或点击“搜索”确认。

顶部标签主题显示笔数和净花费，点击即可筛选。给已选账单添加标签，或把账单拖到主题上；一笔可以有多个标签，始终保留在日期列表。旧用途分组自动转为标签，主题仍可按月建立、改名和删除。勾选可计算净消费，右键可编辑、添加标签、切换计入状态。不计入的条目排在当天末尾；转账、月付还款可手动恢复计入，按支出统计。顶部可调整字号，设置会保留。

将一笔账单拖到另一笔上，可设为后续记录或附属消费，展开查看关联净花费。跨天、跨月记录保留原位置，带关联标记并可跳转到主账单；右键可解除关联或勾选整个关联组。

“月付管理”可归集月付、白条、花呗等账单的消费明细，显示还款金额、明细净消费及差额。消费、退款及提前还款均可跨月归入。系统设置可选择按消费明细或按还款金额计入，保存后应用到现有与新增月付关联。

## 导出备份

在“数据”导出当前月份、连续多月或整本账本。导出的 JSON 包含补记、修改和关联关系，换电脑时可重新导入。建议定期保存整本备份。
