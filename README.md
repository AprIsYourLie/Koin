# Koin

Koin 是一个本机优先的个人消费账本，用来回答一个简单问题：**这个月的钱花到哪里去了？**

## 当前版本

- 按月份统计实际消费总额、每日消费与分类排行。
- 点击顶部账期可选择近 7 天、近 30 天、本周、本月、单日或自定义日期范围，所有统计与明细同步更新。
- 支持新增、编辑、删除支出、退款、收入和不计消费的资金变动。
- 消费明细会显示当前筛选结果的总收入和总支出，并可按关键词、收支类型、分类及账目来源筛选。
- 明细会把有效备注追加到日期、支付方式和来源所在的信息行；导入账单只保留商品说明，不再显示“导入行”和行号。
- 明细金额使用清晰的微软雅黑 UI 字体和左对齐的固定金额列，便于快速区分收入与支出。
- 主页总消费金额使用微软雅黑 UI；每日消费柱状图按金额分为四档，颜色由紫色逐步变为暖色。
- 分开记录“账目来源”和“支付方式”，例如来源为美团、支付方式为花呗。
- 支持直接导入微信官方 XLSX、支付宝官方 CSV，以及通用 CSV、TXT、TSV 账单；压缩包需先解压。
- 账单可以点击选择、拖入导入框，或通过 `Ctrl + V` 粘贴文件及从 Excel 复制的表格内容。
- 支持 Koin JSON 数据备份，并按订单号或“日期 + 商家 + 金额”自动去重。
- 支持按本周、当前月份或自定义日期范围导出 Excel 可直接打开的 CSV 账单，包含来源、支付方式、订单号与备注。
- 页面右侧提供可展开的记账计算器，支持基础运算并可将结果直接带入新账目；移动端可在记账窗口中使用。
- 花呗付款在消费发生月计入支出；花呗还款、信用卡还款、转账、提现、充值和余额互转不计入消费。
- 退款优先作为退款记录冲减统计，保留来源方便后续关联原订单。
- 所有解析和数据保存都在当前浏览器中完成，不需要账号，也不会上传账单。
- 提供响应式布局和可安装网页应用配置，可在电脑或手机浏览器中使用。

## 账单导入

不同平台会调整导出文件的表头与格式。当前解析器会自动识别常见的交易时间、商家、金额、支付方式、状态、收支类型和订单号字段，并兼容 UTF-8 与 GB18030 中文编码。

如果某个平台的文件无法识别，请提供脱敏后的样例：保留原始表头及几行数据结构，姓名、账号和订单号等值可以替换。后续会针对微信、支付宝、抖音和美团的真实样例补充精确适配。

## 本地运行

### 直接打开（Windows）

双击项目目录中的 **`启动 Koin.cmd`**。它会自动启动本地服务并在默认浏览器中打开 Koin；如果服务已经运行，则直接打开网站。

运行期间请保留“Koin 本地服务”窗口。关闭该窗口后，本地网站也会停止；下次使用时重新双击入口即可。

### 开发方式

需要 Node.js 22.13 或更高版本：

```bash
npm install
npm run dev
```

生产构建与测试：

```bash
npm run build
npm test
```

## 数据与隐私

交易记录保存在浏览器本地存储中。清理浏览器数据或更换设备不会自动同步，建议在“数据”页面定期导出 JSON 备份。导入文件不会发送到服务器。
