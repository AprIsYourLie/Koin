# Koin

## 导入账单

打开“数据”，选择整理好的 Koin JSON。导入前可查看月份范围及新增、重复、无效记录数量；确认后，已有记录的本机修改会保留。

## 查看与整理

“概览”按月查看消费、退款和分类趋势；“明细”可连续滚动浏览各月账单，为每个月建立独立的用途分组。顶部功能栏支持搜索筛选、新建分组和勾选求和；右键账单可编辑、计入或不计入、移入分组。不计入的条目排在当天末尾；转账、月付还款也可手动恢复计入，按支出统计。顶部可调整字号，设置会保留。

将一笔账单拖到另一笔上，可设为后续记录或附属消费，展开查看关联净花费。跨天、跨月记录保留原位置，带关联标记并可跳转到主账单；右键可解除关联或勾选整个关联组。

“月付管理”可归集月付、白条、花呗等账单的消费明细，显示还款金额、明细净消费及差额。关联时按消费明细计入，月付还款不计入；支持批量归入与跨月查看。

## 导出备份

在“数据”导出当前月份、连续多月或整本账本。导出的 JSON 包含补记、修改和关联关系，换电脑时可重新导入。建议定期保存整本备份。
