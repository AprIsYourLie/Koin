# Koin

Koin 是一个本机优先的个人消费账本，用来回答一个简单问题：**这个月的钱花到哪里去了？**

Koin 的最终使用形态是 Windows 桌面软件。安装后可从桌面或开始菜单直接打开独立窗口，不需要浏览器，也不需要手动启动命令窗口；账单和设置仍保存在本机。

## 当前版本

- 按月份统计实际消费总额、每日消费与分类排行。
- 点击顶部账期可选择近 7 天、近 30 天、本周、本月、单日或自定义日期范围，所有统计与明细同步更新。
- 支持新增、编辑、删除支出、退款、收入、还款和不计消费的资金变动。
- 消费明细会显示当前筛选结果的总收入和总支出，并可按关键词、收支类型、分类及账目来源筛选。
- 明细优先把有意义的商品说明作为主标题，商家名称放在下一行；“消费”“扫码支付”等通用备注不会取代商家名称。
- 明细金额使用清晰的微软雅黑 UI 字体和左对齐的固定金额列，便于快速区分收入与支出。
- 主页总消费金额使用微软雅黑 UI；每日消费柱状图按金额分为四档，颜色由紫色逐步变为暖色。
- 主页提供可折叠的消费分区，支持在电脑端拖动账目到餐饮、生活、游戏等分类，手机端可用选择器移动；调整后会保存在本机并同步所有统计。
- 分析栏目中的日期、统计金额、笔数和分类排行金额统一使用微软雅黑 UI 与等宽数字。
- 分开记录“账目来源”“支付渠道”和“资金账户”，例如来源为美团、支付渠道为微信支付、资金账户为银行卡。
- 支持直接导入微信官方 XLSX、支付宝官方 CSV，以及银行卡、美团、美团月付、抖音、抖音月付等 CSV、TXT、TSV 账单；压缩包需先解压。
- 账单可以点击选择、拖入导入框，或通过 `Ctrl + V` 粘贴文件及从 Excel 复制的表格内容。
- 支持 Koin JSON 数据备份；重复导入的原始流水按来源、订单号或“日期 + 商家 + 金额”去重。
- 新增“对账”栏目：高置信度的订单、支付和银行卡流水会自动合并为一笔消费并保留全部凭证；仅金额和日期相似的流水会暂不计入，等待手动确认合并或保留为两笔。
- 支持按本周、当前月份或自定义日期范围导出 Excel 可直接打开的 CSV 账单，包含来源、支付渠道、资金账户、是否计入消费、关联凭证数、订单号与备注。
- 页面右侧提供可展开的记账计算器，支持基础运算并可将结果直接带入新账目；移动端可在记账窗口中使用。
- 花呗付款在消费发生月计入支出；花呗还款、信用卡还款、转账、提现、充值和余额互转不计入消费。
- 退款优先作为退款记录冲减统计，保留来源方便后续关联原订单。
- 所有解析和数据保存都在 Koin 当前电脑的专属应用空间中完成，不需要账号，也不会上传账单。
- 提供独立 Windows 窗口与安装包，不依赖外部浏览器或本地网站端口。

## 账单导入

不同平台会调整导出文件的表头与格式。当前解析器会自动识别常见的交易时间、商家、金额、支付方式、状态、收支类型和订单号字段，并兼容 UTF-8 与 GB18030 中文编码。

Koin 将同一消费拆成三类信息理解：订单说明“买了什么”，微信或支付宝说明“通过哪里付款”，银行卡或月付账户说明“最终从哪里出钱”。它们不会被简单相加，而会优先按订单号关联，再按金额、日期、平台与支付渠道进行匹配。花呗、白条、美团月付和抖音月付在消费发生时计入；后续还款只作为资金流水保留，不重复增加消费。

自动匹配必须有明确的平台或支付渠道线索。只有金额与日期相同而证据不足时，Koin 不会擅自合并，而是将其放入“对账”栏目。你可以在那里查看两边的来源、渠道和资金账户，再选择“合并，只统计一次”或“保留为两笔”。

如果某个平台或银行的文件无法识别，请提供脱敏后的样例：保留原始表头及几行数据结构，姓名、账号和订单号等值可以替换。不同银行格式差异较大，后续会根据真实样例补充精确适配。

PDF 账单分两类处理：带文字表格的 PDF 可以在本机解析为 Koin JSON；扫描件需要先做 OCR，并对日期、金额和收支方向复核。若同一银行同时提供可读取版和扫描版，只导入一份，避免重复。当前桌面界面暂不直接接收 PDF，整理后的多平台账单应先合并为一个 Koin JSON，再从“数据 → 导入账单”一次导入。

导入预整理的 Koin JSON 时，文件中已经标记为“待确认”的相似流水会继续保留在“对账”栏目，不会因为金额和日期相同而被强制合并。这样可以先统计证据明确的消费，再由你决定模糊记录是同一笔还是两笔。

## 本地运行

### 桌面软件（推荐）

开发阶段可运行：

```bash
npm run desktop
```

生成可直接运行的 Windows 程序目录：

```bash
npm run desktop:dir
```

程序入口位于 `release/win-unpacked/Koin.exe`。该目录中的其他文件是程序运行所需资源，不能只单独复制 EXE。

生成 Windows 安装包：

```bash
npm run desktop:installer
```

安装完成后可以直接双击桌面上的 Koin 图标使用，不再需要浏览器或 CMD。桌面版采用固定的 Koin 本机空间保存数据，与之前通过 localhost 打开的网页数据相互独立；首次切换时请先从网页版导出完整 JSON 备份，再在桌面版中导入。

### 开发方式

需要 Node.js 22.13 或更高版本：

```bash
npm install
npm run dev
```

生产构建与测试：

```bash
npm run build
npm test
```

## 数据与隐私

交易记录保存在 Koin 的本机应用数据中。卸载时清除应用数据或更换设备不会自动同步，建议在“数据”页面定期导出 JSON 备份。导入文件不会发送到服务器。
